## 🛠️ Step-by-Step Setup Guide

Follow this guide to get up and running on your local computer in less than 5 minutes:

### 1. Install Python
* Go to the [Official Python Website](https://www.python.org/downloads/) and download the latest installer.
* **Windows Users**: During installation, **YOU MUST** check the box that says **"Add Python to PATH"** in the installer wizard.
* **Mac Users**: Simply run the downloaded PKG package installer.

### 2. Install Visual Studio Code
* Download and run the editor installer from the [Visual Studio Code Website](https://code.visualstudio.com/).

### 3. Install VS Code Python & Jupyter Extensions
* Open VS Code.
* Click on the **Extensions** icon on the left-hand activity bar (it looks like 4 squares).
* In the search box, search for **"Python"** (published by Microsoft) and click **Install**.
* Next, search for **"Jupyter"** (published by Microsoft) and click **Install**.

### 4. Open the Workshop Workspace
* In VS Code, click **File > Open Folder...** (or **Open...** on macOS).
* Select this folder (`Python workshop `).
* Click on any of the `.ipynb` files to open them. VS Code will display them as an interactive notebook with rich blocks and playable code cells.
* Click the **"Run All"** button or the play icon next to individual cells to execute them.

> [!NOTE]
> When you run your first cell, VS Code might prompt you to choose a Python interpreter/kernel in the top-right corner. Click **"Python Environments"** and select the Python version you installed.

## 🎨 Why Use Jupyter Notebooks (`.ipynb`)?

Jupyter Notebooks are standard files used by data scientists and software engineers to combine **beautiful instructional formatting** (theory cards, images, notes) and **executable, modifiable Python code cells** in a single interactive canvas. 

Instead of reading dry slides or textbooks, you can edit the code examples directly inside these files, hit play, and immediately see what changes in the computer's output!
